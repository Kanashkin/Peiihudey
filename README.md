# Ешь и Худей

Сайт приложения «Ешь и Худей» (App Store), опубликован через GitHub Pages.

- **Лендинг (RU):** [/](https://kanashkin.github.io/Peiihudey/)
- **Лендинг (EN):** [/en/](https://kanashkin.github.io/Peiihudey/en/)
- **Политика конфиденциальности (RU):** [/privacy_policy.html](https://kanashkin.github.io/Peiihudey/privacy_policy.html)
- **Privacy Policy (EN):** [/privacy_policy_en.html](https://kanashkin.github.io/Peiihudey/privacy_policy_en.html)

## Структура

```
index.html            RU-лендинг (корень)
en/index.html         EN-лендинг
assets/style.css       общие стили для обеих версий лендинга
privacy_policy.html    политика конфиденциальности RU
privacy_policy_en.html политика конфиденциальности EN
```

## Обновление

Правь HTML/CSS в этой папке, коммить и пуш в `main` — GitHub Pages пересобирает сайт автоматически в течение минуты-двух.
